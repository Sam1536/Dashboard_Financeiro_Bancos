# 💰 Dashboard de Lucro e Margem | Power BI

Dashboard interativo que acompanha o resultado financeiro das movimentações: **receita**, **despesas**, **imposto**, **lucro** e **margem**, com evolução do lucro ao longo do tempo, comparação da margem com a meta por município e destaque para as movimentações via **Pix**.

## ✨ Recursos

- Indicadores de **Receita**, **Despesas**, **Imposto**, **Lucro** e **Margem**
- Gráfico de cascata com a evolução do lucro por data da movimentação
- Rosca com o percentual da margem
- Margem por município com desvio em relação à meta, em texto rolante
- Destaque automático com o número e o percentual de movimentações via Pix
- Grade de imagens

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query · Visuais personalizados (Scrolling Text, Enlighten Data Story e grade de imagens)

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
